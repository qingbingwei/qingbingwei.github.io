Agent

本部分用于整理 Agent 相关方法论与实战经验。

建议记录方向

  • 任务拆解与执行流程设计
  • 提示词结构与约束策略
  • 工具调用规范与错误恢复
  • 评估方法：正确性、稳定性、成本与速度

实践模板

  1. 明确目标、输入和输出格式。
  2. 定义可执行步骤与边界条件。
  3. 为关键步骤加入校验与回退逻辑。
  4. 复盘失败案例并沉淀可复用模式。
